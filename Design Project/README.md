# CS 440 Group 4 - Design Project

## SubterraView Design Documentation

This folder contains the design-phase artifacts for **SubterraView**, an AR/AI system concept for underground infrastructure visualization, validation, and hazard monitoring.

## SubterraView Concept Summary

SubterraView is designed to:
- Aggregate data from utility records, city infrastructure databases, and field reports.
- Use AI validation with confidence scoring to resolve conflicting infrastructure data.
- Deliver smartphone AR overlays of underground utilities.
- Integrate hazard sensing workflows for safety alerts.
- Support construction workers, utility technicians, emergency responders, and administrators.
- Operate with 811 compliance as a required constraint.
